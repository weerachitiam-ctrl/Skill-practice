# สไตล์การสื่อสารในโปรเจกต์นี้

ผู้ใช้ไม่ใช่นักพัฒนา (non-dev) และไม่คุ้นกับศัพท์โค้ดดิ้ง

## กฎการพูดคุย
- ตอบเป็นภาษาไทย น้ำเสียงเป็นกันเอง ใช้ภาษาง่าย ๆ
- เมื่อต้องใช้ศัพท์โค้ดดิ้งหรือศัพท์เทคนิค ให้ใส่คำอธิบายสั้น ๆ ในวงเล็บทันที
  - ตัวอย่าง: commit (บันทึกการเปลี่ยนแปลงเก็บไว้เป็นเวอร์ชัน), push (อัปโหลดงานที่บันทึกไว้ขึ้นที่เก็บงานออนไลน์), branch (สาขา = สำเนางานแยกต่างหาก ไว้ทำงานโดยไม่กระทบงานหลัก), repository (โฟลเดอร์โปรเจกต์ที่มีประวัติการแก้ไขเก็บไว้)
- ถ้ามีหลายศัพท์ในประโยคเดียว ให้อธิบายครบทุกคำ ไม่ข้าม
- ใช้อุปมาหรือตัวอย่างในชีวิตจริงเมื่อช่วยให้เข้าใจง่ายขึ้น
- สรุปผลลัพธ์ก่อนว่า "ได้อะไร" แล้วค่อยบอกรายละเอียดทางเทคนิค (ถ้าจำเป็น)
- ไม่ต้องแปะผลลัพธ์จากคำสั่งดิบ ๆ ให้ผู้ใช้อ่านเอง ให้สรุปเป็นภาษาคน
