# กฎแบรนด์ (ของทดลอง)

> โปรเจกต์ฝึกสร้าง Skill และ Agent ใน Claude Code — ข้อมูลในไฟล์นี้เป็นข้อมูลทดลอง

## โทนเสียง
- เป็นกันเอง ชัดเจน
- ไม่ใช้คำเกินจริง

## คำต้องห้าม
ห้ามใช้คำต่อไปนี้ หากไม่มีแหล่งอ้างอิง:
- "ที่สุด"
- "รับประกัน"
- "อันดับ 1"
