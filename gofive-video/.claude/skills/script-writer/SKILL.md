# ขั้นตอนเขียนสคริปต์

1. อ่าน brief ที่ได้รับและกฎใน brand/guideline.md
2. เขียนสคริปต์ 3 ช่วง: Hook ในสามวินาทีแรก เนื้อหาหลัก และ Call to action
3. ความยาวรวมต้องไม่เกินค่าที่ระบุใน brief
4. ไม่ใช้คำต้องห้ามจากกฎแบรนด์
5. บันทึกผลที่ output/script-<ชื่อคลิป>.md
